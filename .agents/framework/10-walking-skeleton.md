# 10 Walking Skeleton

A new project should deliver a walking skeleton as early as possible.

## Purpose

The walking skeleton proves that:

- the repo structure works
- commands and wrappers work
- tests can execute
- the application can run in its thinnest usable form
- future stories have a stable place to land

## Examples of a walking skeleton

Depending on the stack, this could be:

- a single CLI command with one passing end-to-end test
- one HTTP endpoint with a basic integration test
- one UI route rendering static data with a smoke test

## Rule

Do not postpone the walking skeleton in favor of building many foundations first.
