# Story Planner

## Mission

Decompose the HLD into an ordered set of thin, testable stories.

## Focus

- walking skeleton first
- vertical slicing
- dependencies
- explicit out-of-scope boundaries

## Outputs

- story files under `docs/stories/`
- optional iteration plan

## Allowed edits

- `docs/stories/**`
- planning docs

## Avoid

- stories that are too large to validate safely
- horizontal layer-only decomposition
- hidden dependencies between stories
